## Overview

This project explores in-context reinforcement learning for state-machine policies on a physical dexterous manipulation platform. The system was deployed on the Honda Dexterous Hand at Honda Research Institute in San Jose.

## Research Focus

- In-context reinforcement learning
- State-machine policy adaptation
- Dexterous robotic manipulation
- Real-world system deployment
